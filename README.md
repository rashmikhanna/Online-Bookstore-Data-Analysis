# Online Bookstore Data Analysis

## Project Overview
Analyzed online bookstore sales, customer, book, and order data using PostgreSQL and Power BI.

## Tools
PostgreSQL & SQL
Power BI
CSV

## Power BI Dashboard
The dashboard includes:
* Total Revenue
* Total Orders
* Books Sold
* Total Customers
* Average Sales
* Revenue by Genre
* Monthly Revenue
* Top 5 Books Sold
* Top 5 Customers by Spending
* Books Sold by Author

## SQL Analysis
Used SQL for:
* Filtering and sorting
* Aggregation and grouping
* JOINs
* GROUP BY and HAVING
* Revenue and sales analysis
* Customer and book analysis

## Objective
To analyze bookstore performance and present key business insights through SQL and an interactive Power BI dashboard.
